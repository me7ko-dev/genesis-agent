## Капани
- Всеки инструмент казва изрично „нищо“ (празна папка, 0 съвпадения) —
  иначе пазачът за повторения губи хода.
- Кирилица в аргумент на `curl` под Windows → cp1251; през Python/urllib.
- `os.kill(pid, 0)` на Windows е `CTRL_C_EVENT` — Ctrl+C на цялата конзола.
- Жива проба през `Brain()` пише в `budget_log.jsonl` (истински разход).
- PowerShell pipe носи BOM → първата фраза не се разпознава като команда.
- Проверка след „готово“ се връзва И в `genesis_terminal_agent.run_turn`, не
  само в `agent_core` — bench-ът и операторът минават през терминала.
- Пряк `sandbox._run` / `run_python` на Windows иска SYSTEMROOT (WinError 10106
  на `import asyncio`); RUN_CMD минава през Git Bash, който го добавя сам.
- Локален клон без push = работата се прави втори път (10-01 → 10-02).
- ~3 ч bench изчерпват Groq → ollama_cloud/nemotron; времената не се сравняват.
