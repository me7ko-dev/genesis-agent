Направи Python пакет library за малка читалня — папка library/ с отделни модули: __init__.py, models.py (книга, читател, заемане), storage.py (запис в SQLite), service.py (правилата), errors.py (изключенията), cli.py (командния ред). Публичното API: from library import Library, NotFound, NotAvailable, LimitReached. Library(db_path) — данните остават във файла и след ново създаване. add_book(isbn, title, author, copies=1) — ISBN-13 с проверка на контролната цифра (тиретата и интервалите се махат и навсякъде нататък ISBN е само 13-те цифри; невалиден → ValueError); същият ISBN втори път добавя бройки. add_reader(name) -> int (номер на читателя). borrow(reader_id, isbn, on=date) — до 3 книги едновременно на читател (иначе LimitReached), не може същата книга два пъти и не може без свободна бройка (NotAvailable), непознат читател или книга → NotFound; срокът е 14 дни. return_book(reader_id, isbn, on=date) → закъснелите дни (0, ако е навреме). available(isbn) -> int свободни бройки. overdue(today) -> list[tuple[reader_id, isbn, дни закъснение]], сортирани по дни закъснение, най-много първо. python -m library.cli --db файл.db books печата по един ред на книга: ISBN, заглавие, автор, свободни/общо. pytest е инсталиран. Напиши тестове в tests/ и ги пусни, докато минат.
