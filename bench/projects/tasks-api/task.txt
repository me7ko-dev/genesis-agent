Направи малко REST API за задачи с Flask и SQLite във файл app.py. Функция create_app(db_path) връща Flask приложението. Ендпойнти: POST /tasks с JSON {"title": "..."} → 201 и {"id", "title", "done": false}; без title или с празен title → 400; GET /tasks → 200 и списък от всички задачи; PATCH /tasks/<id> с {"done": true/false} → 200 и обновената задача; DELETE /tasks/<id> → 204; несъществуващ id → 404. Данните остават във файла db_path и след рестарт. Flask и pytest са инсталирани. Напиши тестове с test client-а на Flask и ги пусни, докато минат.
