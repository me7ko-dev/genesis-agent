Направи програма за команден ред todo.py за списък със задачи (с argparse). Команди: add "текст" [--priority N] → записва задачата и печата само id-то ѝ (число); list [--all] → по един ред на задача, само незавършените (с --all — всички), подредени по приоритет (1 е най-важният), после по id; done ID → отбелязва задачата като завършена; несъществуващо ID → съобщение на stderr и код за изход 1. Ред при list: "[ ] 3 (P1) Купи хляб" за незавършена и "[x] 3 (P1) Купи хляб" за завършена. Задачите се пазят в JSON файл. Кой файл и какъв приоритет по подразбиране — първото намерено печели, в този ред: флаговете --file и --default-priority (пишат се преди командата: todo.py --file x.json add ...), после променливите на средата TODO_FILE и TODO_PRIORITY, после конфигурационният файл todo.toml в текущата папка (ключове file и default_priority), иначе tasks.json в текущата папка и приоритет 2. Приоритетът е 1, 2 или 3; невалиден приоритет, откъдето и да дойде → съобщение на stderr и код за изход 2. pytest е инсталиран. Напиши тестове, които пускат програмата през subprocess, и ги пусни, докато минат.
