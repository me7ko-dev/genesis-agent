Направи Python пакет sklad за малък склад, разделен на модули. sklad/models.py — dataclass Product(sku: str, name: str, qty: int, price: Decimal). sklad/storage.py — load(path) -> dict[str, Product] и save(path, products) в JSON файл; цената се пази като низ („12.50“), за да не губи точност; липсващ файл → празен склад. sklad/service.py — receive(products, sku, name, qty, price) добавя продукт или увеличава наличността му; issue(products, sku, qty) намалява наличността, а ако няма достатъчно или sku не съществува — хвърля ValueError и не променя нищо; low_stock(products, threshold) -> сортиран списък от sku с наличност под прага. sklad/report.py — total_value(products) -> Decimal (сумата на qty × price). sklad/__main__.py — команди: python -m sklad --db склад.json receive SKU ИМЕ БРОЙ ЦЕНА, python -m sklad --db склад.json issue SKU БРОЙ и python -m sklad --db склад.json report (печата всеки продукт и ред ОБЩО със стойността); при грешка — ясно съобщение и код 1, без traceback. Напиши тестове с pytest и ги пусни, докато минат.
