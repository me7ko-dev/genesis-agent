# Genesis от телефона (Android и iPhone)

Агентът остава на компютъра — там са файловете, shell-ът и ключовете.
Телефонът е прозорец към него, както Claude Code на телефона управлява сесия,
която тече другаде. Друго и не може: iOS не позволява на приложение да пуска
процеси, тоест агент на самия iPhone не би могъл да изпълни нито една команда.

```
 телефон (Genesis Remote)  ──── криптирано, през Wi-Fi ────►  компютър: genesis serve
   чат, потвърждения, Стоп                                      същият агент като `genesis`
```

---

## 1. На компютъра

```powershell
genesis serve
```

Показва QR код, адреса и работната папка. Работната папка е тази, от която
е пуснат (като `genesis`). Ctrl+C спира.

- **Windows приложението** (`irm … | iex`, виж [WINDOWS.md](WINDOWS.md)) носи
  всичко нужно, включително уеб версията за iPhone.
- **pip/pipx**: `pipx inject genesis-agent cryptography qrcode` (или инсталация
  с `[mobile]`).
- **Windows защитна стена**: при първото пускане пита — разреши „Private
  networks", иначе телефонът няма да стигне до компютъра.

## 2. На телефона

| | Как |
|---|---|
| **Android** | Свали `genesis-remote-android.apk` от [последния release](https://github.com/me7ko-dev/genesis-agent/releases/latest), отвори го и разреши инсталиране от този източник. Отвори Genesis Remote → сканирай кода. Следващите версии се инсталират върху старата. |
| **iPhone, без нищо** | Насочи камерата към QR кода → отвори връзката. Приложението се отваря в Safari, направо сдвоено. Share → „Add to Home Screen" го слага като икона. |
| **iPhone, истинско приложение (Xcode на Mac)** | `cd mobile && npm ci && npm run xcode` → в Xcode: Signing & Capabilities → Team → твоят Apple ID (безплатен е достатъчен) → избери свързания iPhone → Run. С безплатен акаунт подписът важи 7 дни, после пак Run. |
| **iPhone/Android за разработка** | `cd mobile && npm ci && npx expo start` → сканирай с Expo Go. |

Сдвояването е веднъж: ключът се пази в защитеното хранилище на телефона
(Keychain / Android Keystore) и следващия път приложението се свързва само.

## Какво има в приложението

- Чатът е същият агент като в терминала: същият цикъл с инструментите,
  същата памет, същият модел (виж горе в заглавието).
- Изпълнените инструменти са карти — докосни, за да видиш целия изход.
- **Опасни команди** (изтриване, инсталиране…) идват като карта с
  „Изпълни" / „Откажи". Без отговор до 5 минути — „не".
- **Стоп** (■) спира хода преди следващия инструмент.
- Меню ⋯ → „Нов разговор" или „Отдвои този телефон".
- Ако телефонът загуби връзка или заспи, при връщане показва пропуснатото.

## Извън дома

Телефонът трябва да стига до компютъра. В същата Wi-Fi мрежа — директно.
Отвън най-лесно с [Tailscale](https://tailscale.com) на двете устройства:

```powershell
genesis serve --host 100.x.y.z     # Tailscale адресът на компютъра
```

Не пускай порта (8765) директно към интернет през рутера.

## Сигурност

`genesis serve` означава, че някой може да пуска команди на компютъра ти —
затова:

- **Ключът е само в QR кода.** 32 случайни байта, родени на компютъра; във
  връзката са след `#`, а тази част браузърът не праща по мрежата. По Wi-Fi не
  минава нито ключ, нито парола.
- **Всичко е криптирано** (ChaCha20-Poly1305): който слуша в същата мрежа, не
  вижда разговора и не може да прати команда.
- **Повторено съобщение се отказва**, отговорът е вързан за заявката, а 30
  грешни опита в минута от един адрес спират тези опити.
- **Опасните команди пак питат** — само че въпросът отива на телефона.
- `genesis serve --reset` сменя ключа: всички сдвоени телефони губят достъп.

Уеб версията (iPhone без Xcode) идва от самия компютър по обикновен HTTP.
Съдържанието пак е криптирано, но активен нападател в същата мрежа би могъл
да подмени самата страница. Вкъщи това не е реален риск. В чужда мрежа
(хотел, кафене) ползвай приложението, не уеб версията.

## Ако нещо не тръгва

| Какво виждаш | Какво да направиш |
|---|---|
| „Не стигам до …" | Телефонът и компютърът в една мрежа ли са? Защитната стена на Windows пуска ли genesis? Гост Wi-Fi мрежите често изолират устройствата. |
| „ключът не пасва" | Ключът е сменен (`--reset`) или на същия адрес вече е друг компютър. Меню → Отдвои → сканирай отново. |
| „часовникът е разминат" | Включи автоматичния час на телефона и на компютъра. |
| Камерата не хваща кода | Увеличи прозореца на терминала или копирай реда „Връзка:" под кода и го постави в приложението. |

## За разработка

```bash
cd mobile
npm ci
npm test              # TypeScript клиентът срещу истинския Python сървър
npm run typecheck
npx expo start        # Expo Go
npm run android       # собствен билд (Android Studio)
npm run xcode         # отваря генерирания Xcode проект
```

Протоколът е описан в началото на `genesis_agent/remote_server.py`; другата
му страна е `mobile/src/lib/protocol.ts`. `ios/` и `android/` не се пазят в
git — генерират се от `app.json` (`npx expo prebuild`).

CI (`.github/workflows/`): `mobile.yml` пуска тестовете, сглобява за трите
платформи и билдва iOS приложението с Xcode (симулатор, без подпис);
`native.yml` билдва Android APK-то и го слага в release-а до Windows
приложението.
